# 问题二建模与求解计划

**目标**：在全部硬时限、运输能力、8架实体无人机、14组共享电池和充电周转约束下，联合确定不可拆货箱组批、多点路线、具体飞机、电池、开始时刻与逐箱交付时刻。

**物理口径**：沿用问题一的水平能耗与势能爬升约定。多点路线按每次交付后的剩余载荷逐段重算能耗；每段重新从服务区离地30m作业高度爬升。任务开始时刻从准备开始计，交付时刻取交接完成时刻，返回时刻取最后一段下降完成时刻。

**资源口径**：飞机从任务开始到返航被占用；电池也在该时段占用，返航后按实际SOC和题目两阶段公式充至100%才能重用。同型电池共享，不同型不可混用。题目未给充电桩数量，因此不同电池可并行充电。

**优化方法**：

1. 以问题一18个已核验单点箱组作为可行种子，保持每个原始货箱ID唯一。
2. 完整检查两条路线合并后的服务区访问排列与A/B/C机型，产生至多3站的可行多点路线；每段使用实际剩余载荷。
3. 对候选路线集合做有限宽度束搜索。每个集合通过离散事件资源调度器分配具体飞机、电池与开始时刻。
4. 对任务优先序做确定性邻域搜索，首先消除硬时限违反，再优化加权迟到、加权交付比例、最晚返航、能耗和架次。
5. 收集全部硬时限可行候选，删除被支配方案；用四项指标相对理想值的等权平方距离选主折中方案，并给出及时性、完工时间、能耗和架次数优先的对照方案。

## 输出与验证

- `solve_q2.py`：物理计算、路线合并、飞机电池调度、多目标候选选择、报告与CSV。
- `verify_q2.py`：从原始货箱与航段独立重算每段载荷、能量、时刻、硬时限、飞机冲突、电池冲突、SOC与充电可用时刻。
- `visualize_q2.py`：路线、甘特图、电池占用、逐箱送达与目标权衡。
- `outputs/01a0d71b-q2/问题二结果.xlsx`：模板Q2两表、资源使用、路线明细、目标对照和计算口径。

验证要求：80箱恰交付一次；所有硬时限满足；每架次质量、体积、能量与返航余量满足；同一飞机和同一电池不重叠；电池每次再次使用前已充至100%；工作簿汇总与CSV一致；所有图件完成视觉检查。
