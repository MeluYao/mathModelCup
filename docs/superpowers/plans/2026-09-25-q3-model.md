# 问题三运输—中继联合调度实施计划

## 建模口径

- 继承问题二的80个不可拆货箱、运输路线能耗、准备/装卸/交接时间、8架运输机及14组共享电池。
- 运输机从起飞开始至返回O01持续检查通信；准备和装载阶段位于O01工位，不计入空中通信保障区间。
- 直接链路不可用时，必须同时满足运输机—中继接入链路和中继—G01回传链路；不允许中继间多跳。
- 地形遮挡由30米DEM沿端点视线剖面判断；传播损耗采用题目给出的FSPL、10 dB遮挡损耗和双向链路门限。
- 中继架次从O01准备、飞抵悬停点、建链、服务、返航；同一中继机和同一能源组件不得重叠，组件再次使用前充至100%。返航后300秒周转时间仅约束中继机的下一架次，联合任务完成时间取返航时刻。

## 求解方法

1. 将运输架次展开为爬升、巡航、下降和交接的连续分段轨迹，以10秒网格并加入全部阶段端点进行通信检查。
2. 在DEM范围内生成候选悬停点，枚举离地高度；筛除回传链路不可用或中继往返能量不可行的点。
3. 对每个运输架次计算直接链路失效区间和可完整覆盖该区间的候选悬停点。
4. 对问题二的不同非支配运输方案进行候选点集合覆盖和指派搜索，使任一时刻所需中继点不超过两处，并减少中继位置数、服务时长和切换。
5. 合并同一点相邻服务区间，在能源上限下切分中继架次；分配R01/R02与6组能源组件并检查准备、建链、返航、周转和充电。
6. 对可行联合方案比较配送及时性、联合完成时间、运输与中继总能耗、运输架次和中继架次，采用硬约束优先、非支配筛选和归一化理想点选取主方案。

## 验证与输出

- 独立复算80箱交付、运输载荷/能量、运输及中继资源互斥、中继能源、悬停高度和通信链路。
- 输出运输架次、逐箱交付、中继架次、通信保障明细、资源占用、目标对照、可视化图和Excel工作簿。
- 组合部分采用确定性启发式搜索；报告将区分“已搜索候选集非支配解”和全局最优证明。
