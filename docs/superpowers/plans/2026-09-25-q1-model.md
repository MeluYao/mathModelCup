# 问题一建模与精确求解计划

**目标**：完成三机型×15服务区最大安全载荷、80箱不可拆组批、多目标比较、安全余量敏感性及可复现实验。

**范围**：用户已要求执行完整建模求解。沿用已核验的预处理数据；只计算O01—单服务区—O01。不加入第二问的实体飞机、电池充电和配送时限约束。

**方法**：单调能耗函数二分求根；按同区同质量体积物资的数量向量完整枚举可行架次；有限状态动态规划精确求解字典序目标。以独立MILP验证最少架次及其能耗最优性。另构造最少架次条件下的能耗—作业时间Pareto前沿与精确架次阶跃阈值。

## 计算口径

- Ehor=Euse*d/L(q)，Eup=(m0+q)*g*h/(eta*3.6e6)，g=9.80665m/s²。前两式为预处理已明确的推导约定，正式报告中再次披露。
- 去程有效载荷q，返程有效载荷0；单架次能量不超过(1-rho)Euse。
- 单架次作业时间=准备+逐箱装载+往返飞行+基础交接+逐箱交接；不添加缺失的运输悬停能耗或周转参数。
- 默认rho=20%；主目标N→E→T；对照E→N→T、T→N→E、N→T→E。
- 安全载荷上限仅反映质量与能量；具体箱组再施加体积及不可拆约束。

## 重点验证

1. E(0)已超预算时记不可达，不把q=0伪装成可行。
2. 同类箱压缩只因第一问不含时限；还原到原箱ID后不得重复或遗漏。
3. 数量动态规划完整枚举，不用“每架尽量装满”贪心代替最优性。
4. 时间含准备与交接，返回SOC计算不四舍五入后再判约束。
5. 敏感性不可行场景明确列出无法服务地区；阈值等号一侧仍可行。

**验证标准**：全部箱组满足硬约束；逐区MILP目标与动态规划一致；Pareto点互不支配；原始附件哈希不变。
