# D 题第一问三方法求解设计

## 目标

建立统一的单点往返物理模型，分别使用最佳适应递减启发式、多目标动态规划和集合划分 MILP 求解货箱组批，并给出逐架次方案、三项指标、算法耗时及返航安全余量灵敏度。

## 统一计算口径

- 架次形式为 `O01 -> Si -> O01`，不得跨服务区组批。
- 计划巡航海拔为直线航段穿过的 DEM 像元最高高程加 50 m。
- O01 作业高度为节点海拔，服务区作业高度为节点海拔加 30 m。
- 水平能耗采用 `E_use * d / L_g(q)`，爬升能耗采用 `(m_g + q) * 9.81 * h / (3.6e6 * eta_g)`。题面未显式印出两个子公式，结果中必须声明这一假设。
- 去程载荷为本架次货箱总质量，返程载荷为 0；下降附加能耗为 0。
- 最大安全载荷使用二分法求解。组批同时满足标称载重、装载体积和返航安全余量。
- 累计作业时间包含准备、逐箱装载、往返飞行、基础交接和逐箱交接，不包含实体无人机、电池、充电、通信或并行排程。

## 三种方法

1. **最佳适应递减启发式**：货箱按质量和体积难装程度递减排序，选择剩余质量和体积最小的现有架次，随后执行两架合并和同组合机型替换。
2. **多目标动态规划**：状态为四类货箱已配送数量，枚举可行候选架次，按 `(架次数, 累计作业时间, 总能耗)` 词典序选择精确最优路径。
3. **集合划分 MILP**：每个候选架次对应非负整数变量，四类货箱采用精确覆盖等式；分三阶段依次最小化架次数、时间和能耗。

动态规划是主算法，MILP 独立复核最优目标，启发式提供快速基线。

## 输出与验证

输出三份逐架次 CSV、方法比较、安全载荷、安全余量灵敏度和 Markdown 汇总。每个结果必须满足 80 箱恰好覆盖、同区组批、质量体积可行、返航 SOC 达标；动态规划与 MILP 的词典序目标必须一致。
