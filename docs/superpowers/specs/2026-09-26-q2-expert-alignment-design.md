# 第二问专家口径对齐与能耗标定敏感性设计

## 目标

使第二问物理口径与论坛专家答疑的证据边界一致，并增加标准航程能量标定的 0.8/1.0 对照实验。基准解仍采用 `range_energy_fraction=1.0`，不改变当前发布结果。

## 文档修订

在《D题第二问当前物理口径说明》中明确：

1. 所有共享电池初始以 100% SOC 位于 O01；
2. 每架次仅携带一块工作电池，不携带备用电池；
3. 基准模型仅允许在 O01 换电和充电，这是因异地电池转运、充电和换电耗时缺失而采用的保守限制，会收缩可行域；
4. 水平与爬升能耗公式属于建模补充，不是专家确认的唯一原式；
5. 增加 0.8 与 1.0 两种航程—能量标定口径及适用解释。

## 实现方案

为 `solve_grouped_local_search` 及其所有生成、修复、合并和重选机型路径增加默认值为 1.0 的 `range_energy_fraction` 参数，并在每次 `evaluate_trip` 时显式传递。默认调用行为保持不变。

独立校验器同步接受该参数，使用相同标定口径重新计算每个架次，避免替代口径结果被默认 1.0 校验器误报。

敏感性分析新增 `range_energy_fraction` 因子，水平取 0.8 和 1.0。每个水平都重新运行分组局部搜索并独立校验，而不是对既有结果做事后比例缩放。输出继续写入统一的 `sensitivity_analysis.csv`。

敏感性图由固定 2×2 调整为可容纳五类因子的 3×2 子图，未使用的子图关闭。基准水平映射中新增 `range_energy_fraction: 1.0`。

## 未采用方案

- 事后将总能耗乘 0.8：无法正确处理爬升能耗、SOC、充电时间、能量可行性和路线重优化。
- 通过放大空载/满载航程间接模拟：数值上可近似等价，但会污染输入语义和报告解释。

## 测试与验收

1. 先增加失败测试，要求敏感性结果包含 `range_energy_fraction` 的 0.8、1.0 两行；
2. 验证 0.8 标定下同一代表架次的水平能耗下降、持续时间不变，且独立校验通过；
3. 验证默认 1.0 行与原基准行为一致；
4. 验证五类敏感性图仍同时生成 PNG/PDF；
5. 运行第二问相关测试和完整测试集；
6. 重新生成 stage3 实验输出，核对 CSV、图表、摘要与物理口径文档。

## 边界

本次不实现服务区电池转运、异地充电或中途换电状态模型；只把 O01 限制明确为保守假设。也不改变基准目标、四方案算法或 20% 返航余量。
