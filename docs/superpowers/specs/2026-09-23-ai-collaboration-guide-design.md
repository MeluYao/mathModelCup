# AI 协作指南设计

## 目标

提供一份可复制到成员 AI 工作目录的 Markdown 指南，使数学背景成员可通过 Codex 或 Claude Code 安全参与仓库协作，而无需直接操作 Git。

## 交付物

在仓库中维护 `docs/AI_COLLABORATION_GUIDE.md`。成员将其复制到个人工作目录，并要求 AI 在任何仓库操作前先阅读。

## 内容结构

1. 使用方式与可复制的启动提示词。
2. AI 与成员的职责边界，特别是外部邀请、公开仓库、删除和权限变更必须由成员确认。
3. 标准协作流程：同步 main、功能分支、实现与测试、提交、推送、Pull Request。
4. 赛题材料、数据、输出与临时文件的禁止上传规则。
5. 数学建模目录约定与 Conda 环境使用。
6. Codex 和 Claude Code 的通用任务提示词。
7. 冲突、误暂存和环境失败的恢复步骤。

## 约束

- 指南使用简体中文，工具无关，不含账号密码或令牌。
- 每个 Git 操作均包含可直接向 AI 提出的自然语言请求，而非要求成员输入 Git 命令。
- 与本仓库 `.gitignore` 和 Python 3.11 Conda 环境约定保持一致。
