# AI 协作指南设计

## 目标

提供一份可复制到成员 AI 工作目录、直接面向 AI 的 Markdown 操作规范，使 Codex 或 Claude Code 代替数学背景成员安全完成 Git 协作。

## 交付物

在仓库中维护 `docs/AI_COLLABORATION_GUIDE.md`。成员将其复制到个人工作目录，并要求 AI 在任何仓库操作前先阅读。

## 内容结构

1. AI 启动规则：识别当前成员账号并读取项目说明。
2. 固定分支映射：`yf82289878` 使用 `yf82289878`，`lyn18302` 使用 `lyn18302`。
3. AI 与成员的职责边界，特别是外部邀请、公开仓库、删除和权限变更必须由成员确认。
4. 标准协作流程：同步 main、创建或切换账号分支、实现与测试、提交、推送、Pull Request。
5. 赛题材料、数据、输出与临时文件的禁止上传规则。
6. 数学建模目录约定与 Conda 环境使用。
7. 中文 commit 注释规范与示例。
8. 冲突、误暂存和环境失败的恢复步骤。

## 约束

- 指南使用简体中文，工具无关，不含账号密码或令牌。
- 说明以 AI 为唯一读者，成员无需阅读或执行 Git 命令。
- AI 不得为每项任务随意创建新分支，也不得直接修改 `main`。
- 所有 commit 注释必须使用简体中文。
- 与本仓库 `.gitignore` 和 Python 3.11 Conda 环境约定保持一致。
